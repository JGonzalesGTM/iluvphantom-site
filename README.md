Static PHANTOM lifestyle site for iluvphantom.com. No build step: serve the `dist/` folder.

Preview: `python -m http.server 4173 --bind 127.0.0.1 --directory dist`, then open http://127.0.0.1:4173

See `HANDOFF.md` for design notes, open questions and deployment cautions (no deployment has been done; preserve MX/mail DNS).
